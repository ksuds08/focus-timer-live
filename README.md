# Focus Timer Live

A clean, distraction-free Pomodoro focus timer built with plain HTML, CSS, and vanilla JavaScript.

## Features

- **25/5 Minute Presets**: Switch between a 25-minute Focus session and a 5-minute Short Break.
- **Smooth Controls**: Start, pause, resume, and reset with clickable buttons or keyboard shortcuts (`Space` to start/pause, `R` to reset).
- **Gentle Completion Chime**: Built-in Web Audio chime with a saved on/off toggle and sound preview.
- **Saved Session Counter**: Automatically tracks and saves completed focus sessions in `localStorage`.

## Running Locally

Open `index.html` in any modern web browser—no build step or dependencies required.
